# Third-party sources

What ggtts takes from other projects, and under which licence. Release archives carry this file, `LICENSE`,
`licenses/` and the licence files beside the vendored sources under `instruments/`.

**Linked into the binaries.** ggml is linked statically into every engine build; its licence text, with its
copyright line, is `licenses/ggml-LICENSE.txt`, a copy of the submodule's `LICENSE`. Every Rust crate linked into
`ggtts-render` and `ggtts-measure` is listed in `licenses/rust-crates.txt` with its version, licence expression and
licence texts. That file is generated by `scripts/third_party_notices.py` from the resolved dependency tree and each
crate's own source; it is not written by hand, and CI and the pack step fail when a linked crate is missing from it.
The table below says what is taken from each project and why; for crates it is not the list of what is linked.
