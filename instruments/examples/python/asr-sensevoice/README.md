# Optional CPU SenseVoice instrument

`asr-sensevoice` is an ordinary post-render instrument. It reads the completed audio and a local UTF-8 reference file, runs a locally installed SenseVoiceSmall model on CPU, and reports a character error rate. It never changes audio or the render's per-draw judge. It is opt-in; install `funasr` and its CPU dependencies separately and provide a complete local model directory. Missing files, missing dependencies, or invalid/empty recognition fail rather than report zero. The existing runner's timeout, `on_error`, and `--require` rules still apply.

For example, configure `asr-sensevoice` with `arg.model_dir=/local/model` and `arg.reference_file=/private/reference.txt`, and set a suitable timeout. Supply file paths, never the reference text or secrets as arguments. Use non-sensitive filenames: the SDK records basenames and SHA-256 hashes of inputs. Absolute model/reference paths are removed from this instrument's envelope config, but operating-system errors and external configuration can still expose paths. Keep the reference and model outside git. The report records model file hashes, software version, CPU settings, and audio state `unknown`; the caller must independently record the actual trim history.

The metric uses Unicode NFKC, case folding and alphanumeric characters; it does not perform traditional/simplified Chinese conversion. Character error is descriptive, is sensitive to spelling and script differences, and is not a measure of naturalness, accent, preference or quality. A missing transcript, null comparison, or failed control is not evidence that speech is complete. The included fake recognizer tests verify mechanics, not real model sensitivity. Before using it to rule out an omission, register the task-specific inputs and demonstrate detection of a relevant planted omission and a no-op floor. Quality decisions still require the matched base and owner listening.
